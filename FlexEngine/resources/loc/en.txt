# English text for every string shown to the player. English is the source language: other languages
# (<code>.txt files beside this one) fall back to it for any keys they leave out.
#
# Each line is Key = Text. Keys are Area_Name & are used in code as LOC(Area_Name), or LOCF(Area_Name, args...) when
# the text has printf-style arguments (%s takes a const char*). Wrap the text in "quotes" to keep leading or trailing
# spaces; \n is a new line. Lines starting with # are comments. Edits are reloaded while the game runs.
